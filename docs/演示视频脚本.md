# ClawPlanOps 演示视频脚本

> 时长：1-2 分钟

---

## 开场（10 秒）

**画面：** 终端界面

**旁白：**
> 大家好，我演示的是 ClawPlanOps，一个基于交付物证据的项目执行规划插件。

---

## 问题引入（15 秒）

**画面：** 展示传统项目管理的痛点

**旁白：**
> 在比赛中，我们经常遇到这些问题：计划制定了但难以追踪进度，材料提交前才发现遗漏。ClawPlanOps 解决了这些痛点。

---

## 核心功能演示（60 秒）

### 功能 1：任务解析（15 秒）

**画面：** 终端运行命令

```bash
node dist/cli.js parse examples/zzu_four_creation_notice.txt
```

**旁白：**
> 输入一段比赛通知，自动提取任务名称、截止时间、交付物。

### 功能 2：计划生成（15 秒）

**画面：** 展示生成的计划

```bash
node dist/cli.js plan requirements.json
```

**旁白：**
> 根据交付物反向拆解，生成 3 个阶段、27 个微任务。

### 功能 3：进度检查（15 秒）

**画面：** 展示进度检查结果

```bash
node dist/cli.js check .
```

**旁白：**
> 扫描项目文件和 Git 提交，自动判断进度。当前进度 64%，发现 3 个缺失材料。

### 功能 4：提交前检查（15 秒）

**画面：** 展示检查报告

```bash
node dist/cli.js presubmit . plan.json
```

**旁白：**
> 提交前自动检查所有材料是否齐全，给出评分和缺失项。
