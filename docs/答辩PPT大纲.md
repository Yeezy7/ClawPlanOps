## 第 1 页：问题背景

**标题：** 项目管理的痛点

**内容：**
- 计划与执行脱节
- 进度更新依赖人工
- 材料提交容易遗漏
- 多项目管理困难

**视觉：** 用 emoji 或图标表示痛点

---

## 第 2 页：解决方案

**标题：** 基于证据的进度追踪

**核心理念：**
> 不靠用户打卡，而靠真实文件证据检查进度

**流程图：**
```
任务通知 → 自动解析 → 生成计划 → 导出日历
                                      ↓
           动态重排 ← 检查进度 ← 扫描文件 + Git
```

---

## 第 3 页：功能展示

**标题：** 核心功能

| 功能 | 说明 |
|------|------|
| 📋 任务解析 | 从通知文本提取结构化信息 |
| 📅 计划生成 | 反向拆解交付物为微任务 |
| 📆 日历导出 | ICS 文件含提醒 |
| 🔍 进度检查 | 扫描文件 + Git 证据 |
| 🔄 动态重排 | 自动调整计划 |

## 第 8 页：总结

**标题：** 项目总结

**三个核心亮点：**
1. 从任务要求自动生成计划
2. 从最终交付物反向拆解微任务
3. 不靠用户打卡，而靠真实文件证据检查进度

**一句话介绍：**
> ClawPlanOps 是一个基于交付物证据的项目执行规划插件，能从任务通知中识别要求，生成计划，并通过检查真实文件进度判断任务是否完成。
